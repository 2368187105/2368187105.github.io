# 复习、测评与打印

## 数据库安装

在已有项目的 Supabase SQL Editor 新建查询，完整运行同目录 `learning-workspace.sql`。不要替换旧建表脚本，也不需要删除任何表或记录。

脚本新增 `mistake_reviews`（错因及状态）、`mistake_review_events`（状态历史）、`weekly_review_plans`（每周清单）、`chapter_assessments`（测评快照），以及事务保存函数。可以重复运行，原有练习、错题、学习时长与排行榜不变。

各表开启 RLS，仅当前用户可读取自己的数据。历史事件不允许客户端改写。测评通过 RPC 一次性写入测评与 12 道答题记录，失败回滚；同一场测评重试不重复计数。它是自学工具，客户端判分与学生自评不作为考试认证成绩。

## 使用入口

- 错题本：按四种错因、三种掌握状态筛选；每题保存分类，查看最近 20 条状态变化。更早历史保留在云端。答错自动回到待复习，答对进入复练中；标记已掌握仍保留题目。
- 学习报告：选择年级后保存本周最多 5 题的复习清单。按北京时间周一分周。对应课程链接来自实际课程目录；生成后的新作答决定完成状态。解答题自评完整与客观题重新答对分别显示。前后正确率带样本量，不代表因果或整个专题已经掌握。
- 高三 → 八章综合训练 → 限时测评：每章原有 12 题，45 分钟、60 分。6 道选择和 3 道填空各 4 分，3 道解答各 8 分。解答题的检查点按 8 分分配（现有三步为 3、3、2），各步可给 0 到该步满分，含自评分数会明确标记。
- 交卷后锁定答案、展开完整解析；完成自评才能保存云端。已存测评可从报告重新查看。退出账号会停止当前界面；游客草稿与账号草稿分开，不能自动转入其他账号。
- 专题训练、错题本、章末综合均有打印入口。可选择题目版或完整解析版；点击打印，在系统窗口选择打印机或“另存为 PDF”。按 A4 纵向排版，不是直接下载生成的 PDF 文件。

## 暂存与边界

测评作答在当前浏览器、当前账号下本机暂存，截止时间不随刷新重置；切到后台仍计时，回来或截止后自动锁卷。交卷前的草稿不会自动跨设备同步。浏览器清理站点数据会清除未保存的草稿；暂存失败会在页面明确提示。

客观题与解答自评沿用已有记录格式，测评保存后计入原学习报告、错题和排行榜；解答题不计入客观题正确率。仅完成浏览页面或一次答对不会自动标记“已掌握”。
