# 关键词搜索与整组提交

首页提供搜索框，全站导航提供“搜索”入口。搜索课程名称、章节名称、知识点、题目标题、题干及题目公式；多个关键词以空格分隔，同时匹配。不索引参考答案和解析。支持年级、课程/题目筛选，每次展示 20 项。搜索结果中的题目打开单题练习，课程直接打开原有课程页面。

专题训练以现有专题为一组，今日训练以首页安排为一组。答题卡可跳题、返回修改；浏览器按账号与实际题目列表保留草稿。刷新不会自动提交。切换账号不会带入另一个账号或访客的草稿。云端同步的仍是原有练习记录，草稿本身只存本浏览器。

选择和填空整组一次提交。含解答题时，先完成整组独立作答，再核对解答题的完整解析并完成分步自评，最后一次提交整组。客观题解析在最终提交后显示。自评阶段可返回修改作答，这会清空本组旧自评，要求重新核对。纸上作答、录入草稿、提示、完整解析、逐步自评和订正备注均保留。

提交时保持原有问题 ID、表和权限。答题记录一次批量插入，错题逐题同步。提交时间固定并随草稿保存；重试先按当前账号、题目 ID 和提交时间核对已确认的记录，只补写缺失记录，避免错题同步失败时重复插入答题记录。浏览器支持 Web Locks 时还会串行执行同源多标签页对同组的保存。此机制不是数据库唯一键或跨设备分布式事务；需要跨设备严格幂等时应另加服务端事务及提交 ID。网络失败明确提示未确认，保留本地结果，提供重试；页面不自动重复提交。

错题本、报告中的原题复练和变式链接使用单题组。章末限时测评及课程课堂自测保持原有整组作答方式。没有删除原有课程、题库或组件。

维护入口：

- `src/lib/site-search.ts`：搜索索引、匹配与排序。
- `src/app/search/page.tsx`：结果展示和筛选。
- `src/components/SearchForm.tsx`：首页及搜索页的输入框。
- `src/components/PracticeBatch.tsx`：答题卡、草稿、核对自评和整组结果。
- `src/lib/practice-batch.ts`：草稿校验、判题与云端批量保存。
- `src/app/practice/page.tsx`：原有年级/章节/专题导航和题组选择。
- 原有课程仍在 `src/app/grade1`、`grade2`、`grade3` 的各节 `page.tsx`，题目仍在 `src/data/questions-part*.ts`，本轮未改题目内容。

验证：`npm run check:search-batch` 检查全部 132 节课程、813 题的可检索性、混合题型、草稿校验、保存失败、已确认记录重试和账号隔离；其他学习/课程/每日安排回归检查继续运行。浏览器使用本地访客验证作答提交，正式站只做只读检查，不往真实学习账号写入测试答案。
