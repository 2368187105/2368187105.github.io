# 高三一轮复习发布验收

日期：2026-10-21。

## 内容范围

- 高一 50 节课程、150 题，高二 30 节课程、90 题。
- 高三八模块 52 节课程、468 道配套题，保留原有 9 道函数复练题。
- 新增八章综合训练，每章 6 道选择、3 道填空、3 道解答，共 96 题。
- 高三共 573 题，全站共 813 题；原有 717 道题的 ID、内容及答案保持不变。

## 1. 学习记录与错题

已完成代码修复和模拟检查：三类题共用云端保存入口；保存失败明确提示；重复答错时更新当前用户该题的最新答案；错题链接直接定位指定题；客观题成绩与解答题自评分开统计。

运行 `npm run check:learning` 可检查答案别名、无效输入、统计分离，以及云端写入失败、重复错题更新的模拟场景。该检查不等于真实数据库写入验收。

正式站已使用登录账号完成五次真实提交：同一选择题连续两次答错后保留一条错题并更新为最新答案，通过错题链接重练答对；填空题接受等价区间写法并保存；解答题保存草稿及三步自评，加入需复练错题。报告刷新后记录仍一致，客观题与自评分开统计，高一原有记录未改变。真实错题页面已确认最新错误答案、完整解析和三项自评仍在。验收记录保留，未执行删除。

## 2. 数学与显示

- 八模块原有数学计算及边界条件检查共 4,882 项；新增综合训练独立计算与结构检查共 2,801 项，均通过。
- 全部 813 道题中的 253 个含根式字段、510 组外层根式渲染通过；18 个解析器边界用例通过，包括嵌套根式。
- 生产构建与 TypeScript 检查通过，共 172 个静态页面；静态页面中的 2,646 个站内链接未发现缺失目标，根式扫描未发现裸根号或 KaTeX 错误。
- 手机实际宽度 375px 下抽查首页、高一基本不等式、高二直线距离、高三统计推断、空间动点和专题训练，未发现整页横向溢出或 KaTeX 错误。
- 这些检查覆盖程序可验证的计算、边界和显示，不代表对每一段文字完成了独立人工审校。

## 3. 综合训练

八个模块目录、高三总目录和首页均增加入口；题库沿用现有 `Question` 类型与分组方式，新增题目集中在 `src/data/questions-part13.ts`。原有课程、例题、交互图形和题目均保留。

浏览器已逐个打开八个章末专题，确认各有 12 题。指定题链接可以直接打开第 12 题；嵌套根式与三项自评正常显示。未登录状态的自评提交明确提示不保存到云端，客观题题次数保持为零。新增定义域填空题补充了区间与常见不等式的等价写法，并检查错误端点仍判为未匹配。
