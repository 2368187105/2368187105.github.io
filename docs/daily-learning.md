# 每日学习与间隔复习

2026-10-22。修改前备份：`.backups/before-four-step-improvements-20261022.zip`，不含环境密钥。

## 四步实现

1. 长解析使用 `SolutionText`：连续长计算式在本行滚动，普通正文正常换行；打印时恢复可折行。训练、错题、测评、打印共用这一出口。账号边界在身份改变时卸载旧记录，未完成的旧查询由原有清理函数阻止回写。登录入口带安全的站内返回位置，成功后回原题或报告。
2. 首页“今天学什么”：按所选年级读取本人答题记录，优先安排到期复习，再安排有依据的变式与薄弱专题巩固。每日目标五道不同题目，重复提交不重复计算目标进度；题组最多五题、最多一道解答题。预计时长仅为安排参考。题组沿用原 `/practice/` 页面和保存逻辑，不另建课程或题库框架。
3. 间隔复习：历史上答错过的题目或已有复习档案进入安排。再次答错为当前可复习；答对后按不同北京时间日期累计连续复习日，依次隔 1、3、7 天；手动已掌握后隔 14 天回顾。当天重复答对不增加跨日次数。所有安排从原记录推导，无新增数据库脚本。报告同时保留原周清单。
4. 纸上解答：训练页默认纸上作答，明确确认已独立尝试后才能展开完整解析；逐步自评必填，订正备注选填，原录入草稿模式保留。测评支持纸上尝试标记、可选步骤录入、12 题答题卡与待检查星标；标记随原本机测评草稿保留。

## 数据规则与限制

- 保留原来 813 道题的内容和 ID，仍写入原 `practice_attempts`、`mistakes` 等表。课程、例题和图形文件未迁移。
- `self:` JSON 继续作为解答题自评记录，增加可选 `mode: "paper" | "typed"`。旧记录没有 `mode` 时继续按原草稿展示。纸上模式的 `work` 是可选订正备注；界面明确纸面过程没有上传。客观题正确率仍排除所有解答题自评。
- 本轮没有照片上传、识别或自动阅卷功能。纸上尝试确认和学生自评不等同于教师批改，也不自动证明知识已掌握。
- 变式映射有 15 组，逐组查看原题后建立，覆盖高三八个模块的部分知识点。没有已核对配对时，入口明确称“同专题巩固”。不把任意一道同专题题冒充等价变式，也不宣传全题库都有配对。
- 薄弱专题按近七天、至少三次客观题作答给出建议，显示样本数量；重复作答可能影响这一参考值。没有足够记录时不虚构掌握程度。
- 首页最近练习来自本人云端记录；课程阅读位置仅保存在当前浏览器、按账号隔离，并从实际课程目录核验，不能声称跨设备恢复课程位置。
- 每日目标按不同题目计算“已练习”，不意味着全部答对。到期题多于五道时先安排一组，其余保留。
- 登录返回地址只接受本站学习路径，拒绝外部地址、协议相对地址、反斜线及凭据片段；密码找回流程保留。
- 本机已有测评草稿与云端旧场次均兼容。新增可选 `paperAnswers`、`flagged` 通过校验后恢复；退出账号不会把草稿转入其他账号。

## 验证

运行 `npm run check:daily` 验证复习间隔、同日去重、重新答错、变式映射、按年级组题、解答自评隔离、安全返回、账号竞态、纸上测评草稿兼容和 132 个具体课程映射。原学习记录、排行榜、课程目录、复习工作区和密码找回检查继续保留。

这些程序检查不执行真实云端写入。正式站验收不得用编造记录填充个人数据或排行榜；浏览器截图和逐页检查结果保存在本地忽略目录。

本轮本地验收：生产构建、TypeScript 与 ESLint 错误检查通过；上述五组原有回归及新增 `check:daily` 通过。工作区 PostgreSQL 检查额外验证纸上作答空备注、星标草稿字段、原子保存与重复保存，仍保留旧格式测试。174 个导出文件中的 3,446 个站内链接和锚点通过检查。

浏览器实际逐个检查 171 个内容页的 375px 手机与 1280px 桌面默认状态；143 个专题的 813 道题完整解析另以手机宽度逐个检查，未发现整页溢出或 KaTeX 错误。实际操作题组跨专题切换、刷新定位、纸上确认与三步自评、测评答题卡、纸上标记与星标刷新恢复、交卷后空白题计零及纸上题评分启用。操作使用本地游客环境，没有向真实账号添加试验答题记录。跨账号竞态通过隔离测试验证，未操作用户的第二个真实账号。
