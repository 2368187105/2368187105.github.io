# 首页竞赛证书宣传区

位置：首页主介绍下方、学习统计上方。组件 `src/components/HomeAward.tsx`，图片 `public/images/math-competition-2018.jpg`。

采用用户提供的原照片，保留可见的姓名首字“孟”，遮挡后面的姓名区域。页面以 CSS 调整亮度、对比度和饱和度，不重绘证书文字、日期或印章。标题只采用照片可辨认的信息：2018 年、连云港市数学竞赛、高中组一等奖，不补写完整姓名或无法确认的日期。

图片支持点击放大、放大细节、左右滚动、Esc 关闭及键盘焦点管理。手机布局上下排列，桌面左右排列。展示遮挡为网页覆盖层；素材文件本身沿用用户已部分打码的原图。

本轮曾使用内置 image_gen 进行增强尝试，未使用 CLI。提示词要求：轻微校正页面边缘、移除外围背景碎片、改善冷色偏色和可读性；保持纸张质感、所有原文、手写内容、日期、奖项及两枚印章原样；遮挡姓名，不添加宣传文字、装饰或水印。由于生成结果重绘了部分细节，并遮住了用户要求保留的“孟”，该生成版本没有部署。最终网页使用原始照片及上述 CSS 呈现方式。

以后换图时保留图片宽高比，并重新核对 `CertificatePhoto` 内遮挡区域的位置；遮挡框按当前照片的百分比定位。宣传文案和图片展示都在同一个组件中。
